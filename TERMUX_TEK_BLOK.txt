TERMUX TEK BLOK YAYINLAMA

ZIP dosyasını Android Download klasörüne indir. Termux'ta bu bloğu tek seferde çalıştır:

pkg update -y && pkg install -y git gh unzip && termux-setup-storage && mkdir -p "$HOME/ng-publish" && unzip -o "$HOME/storage/downloads/Naxcivan_Goyercin_GitHub_Termux.zip" -d "$HOME/ng-publish" && cd "$HOME/ng-publish/Naxcivan_Goyercin_GitHub_Paket" && bash ./publish_termux.sh

GitHub CLI giriş ekranı açılırsa ekrandaki cihaz kodunu GitHub hesabında onayla. Script:
- yeni ve public bir repo oluşturur,
- dosyaları main dalına gönderir,
- GitHub Pages'i GitHub Actions olarak yapılandırır,
- yayınlama iş akışını bekler ve repo/site bağlantılarını gösterir.

Repo sahibi otomatik olarak admin olur. Script herkese yönetici izni vermez; yalnızca repo ve workflow için gereken GitHub CLI izinlerini ister.
